# 嵌字评分口径变更：碎片条目按并集首尾补算时间分（破坏性）

日期：2026-09-16｜关联：D9（benchmark/OCR_PIPELINE_DEFECTS.md）、D9 修复 commit `0a43fbf`

## 背景与触发

D9（合并层修复）实测暴露复合评分反转：glupov 嵌字把断词残句并成完整段后，
复合分 **11.4 → 6.8**——结构轴全面改善（碎片 8→5、1:1 13→16、缺失 0 保持），
分数却下降。用户复核后判定"完整段比碎片段低分明显说不过去"，要求修口径。

## 根因

`score_hardsub` 旧口径下，**碎片条目只罚 `(N−1)×0.5`，完全豁免时间扣分**；
`② 时间轴` 也只报 1:1 配对——碎片条目的时间偏移在所有轴上均不可见。
碎片一旦被合并成完整段（转为 1:1），才第一次按 `d = max(|Δstart|,|Δend|)` 计时：
glupov 计时本就差（Δstart 中位 +1.25s、容差内仅 8%，PR31 P2-2 呈现问题），
每条吃满 1.0，于是"合并越干净、分数越低"。

## 变更内容（2026-09-16）

1. **碎片条目按并集首尾补算时间分**：取该期望条目下所有碎片段的
   `min(start)` → `max(end)` 作为并集，用与 1:1 完全相同的公式计分
   （`timing_penalty`，两分支共用，保证公式字面一致）；结构附加 `0.5×(N−1)` 不变。
   性质：合并段的并集 = 碎片并集 → 时间分相同、结构分更小 →
   **同一期望条目合并后扣分必不高于碎片时（合并永不亏，数学上对所有案例成立）**。
2. **解除复合分 0 钳制**（随本次一并放开）：旧实现 `.max(0.0)` 把扣分截到 ≥0；
   并集计时后单条目扣分可超 1（如碎片 = 时间 1.0 + 结构 0.5），深度缺陷区
   会被钳成同值 0（D9 前后 −25.0/−15.9 将压成 0/0），单调性虽在但分辨率尽失。
   按决策**接受负分**（缺陷求和口径，不封顶）。语料端 `score_corpus` 不受影响。

## 复算验证（glupov 嵌字，D9 前后两份产物日志，容差 0.3s）

复算脚本（temp/probe/recount_score.py，不入库）先以旧口径精确复现 Rust 端
11.4 / 6.8（含 1:1/碎片/吞并/缺失计数逐项一致），再切换口径对比：

| 口径 | D9 前（33 段，1:1 13/碎片 8/吞并 1/缺失 0） | D9 后（29 段，16/5/1/0） | 合并的方向 |
|---|---|---|---|
| 旧（碎片豁免计时 + 0 钳制） | 11.4 | 6.8 | **−4.6（反转）** |
| 新（并集计时，不封顶） | −25.0 | −15.9 | **+9.1（单调恢复）** |

负值是"如实的丑"：glupov 嵌字计时确实差（容差内 8%），旧口径靠碎片豁免
掩盖了这一点。段集合本身在口径变更前后完全一致（评分是纯后处理）。

## 全量复跑（新口径首跑，2026-09-16）

段集合与 D9 后运行**逐项一致**（OCR 段 / 1:1 / 碎片 / 吞并 / 缺失 / 各时间轴
统计全部原值）——证实口径变更纯属后处理，管线行为未动：

| 案例 | 结构（1:1/碎片/吞并/缺失） | 旧口径 | 新口径（首跑） | 差值来源 |
|---|---|---|---|---|
| glupov | 16/5/1/0 | 6.8 | **−15.9** | 5 条碎片补计时（复算 −15.9 与实跑一致）；旧 6.8 系 0 钳制截断 |
| moon | 17/2/0/0 | 18.1 | **15.8** | 2 条碎片补计时（并集偏差较小） |
| pierro | 93/23/3/0 | 15.7 | **−0.4** | 23 条碎片补计时（多数并集超容差） |

语料端复跑**逐位复现**（glupov 92.4 / moon 100.0 / pierro 99.6，含 pierro 噪音 40），
口径变更不影响语料基准。

## 破坏性影响与读数约定

- **复合分历史数字不可跨此口径对比**：benchmark/*.md 嵌字表中 2026-09-16
  之前的复合分行均为旧口径（且受 0 钳制），跨口径比较无效；
  跨版本对比改以 ① 结构轴与 ② 时间轴为准（这两轴口径未变）。
- 新口径下嵌字复合分可为负（如 glupov），属"缺陷求和"的如实读数，
  不代表回归；判读回归时看同一口径下的前后差值。
- 语料基准（score_corpus）口径不变，其历史可比性不受影响。

## 单元测试

- 新增 `hardsub_fragmented_union_timing_monotonic`：干净拆分 50.0 vs 合并 100.0；
  并集偏晚 0.6s 时碎片 −50.0 vs 合并 0.0（两种形态下均满足 合并 ≥ 碎片）；
  3 段碎片 = 0.0（结构 1.0，不封顶口径）。
  该断言首版因保留 `.max(0.0)` 钳制而实测得 0，暴露了钳制会抹平深度缺陷区
  （D9 前后 −25.0/−15.9 将同值 0）——按决策解除钳制后断言通过。
- 既有 `scoring_deductions` / `hardsub_axes_diagnostics` 无碎片计分断言，全部通过
  （bench_hardsub / bench_corpus 两测试二进制各 11 passed）。
